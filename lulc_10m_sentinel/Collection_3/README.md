# 🌿 MapBiomas Pantanal | Sentinel Collection 3 (10m)

This repository contains the JavaScript workflow (pipeline) for Google Earth Engine (GEE), focused on the land use and land cover classification of the **Pantanal Biome** for **Collection 3 (Sentinel - 10m)** of the [MapBiomas](https://mapbiomas.org/) project.

The pipeline covers everything from generating stable samples and extracting *Satellite Embeddings* (Google) to Random Forest classification and robust post-classification filters.

## 📂 Pipeline Structure (Files)

The scripts have been optimized and must be executed sequentially in the Google Earth Engine Code Editor. The numerical naming indicates the exact execution order:

### Step 1: Sampling
* `01_export_stable_samples.js`  
  Filters and exports pixels that remained stable across previous collections, creating a reliable baseline.
* `02_export_collection_mask.js`  
  Applies a spatial erosion filter (*focalMin*) to the stable samples to restrict the masks only to the "core" of each patch, avoiding edge noise.
* `03_extract_embeddings.js`  
  Extracts annual values from the Google *Satellite Embeddings* collection for the sampled points.
* `04_export_trained_samples.js`  
  Merges Sentinel spectral bands, calculated indices (NDDI, NDWI, etc.), topographic variables, and embeddings to export the final training samples (`FeatureCollections`).

### Step 2: Classification
* `05_01_random_forest_reg0.js` *(and equivalents for other regions)* Applies the **Random Forest** *Machine Learning* model, using specific sample balancing rules for each region and year.
* `05_02_merge_and_export.js`  
  Collects individual results from all regions and the background region (Region 0) and blends them into a single annual mosaic (Final raw classification asset).

### Step 3: Post-Classification and Filters
* `06_6_GAPfill.js`  
  Fills pixels with no data or covered by clouds (*Gap Fill*), analyzing classifications in past and future temporal windows (`t-1` and `t+1`).
* `07_spatial_floodFilters.js`  
  Removes local spatial noise (*focal mode*) and corrects false positives of agriculture and pasture in wetlands using historical flood frequency and NDDI thresholds.
* `08_post_classification_master.js`  
  The final master script. Groups and processes with high performance:
  - Mode Filters.
  - Cross-temporal trajectory rules (e.g., conversion between Forest, Savanna, Pasture, and Grassland).
  - Relief and permanent shadow masks (Slope, TRI, Hillshade).
  - Temporal Filter with a 3-year window (removes anomalous transitions).
  - Final minimum area spatial filter to export data for Integration.

## 🛠️ Requirements and Dependencies

To run this project, you will need:
1. An active [Google Earth Engine](https://earthengine.google.com/) account.
2. Read/write access to MapBiomas internal repositories and assets (`projects/mapbiomas-workspace/`).
3. MapBiomas Palettes Module:  
   `require('users/mapbiomas/modules:Palettes.js');`
4. Auxiliary Indices Module:  
   `require('users/gee_arcplan/MapBiomas_Col10_Pantanal:processa_Bandas_Indices_DF_lite');`

## 🚀 How to Use

1. Clone or download this repository to your local machine.
2. Copy the contents of the scripts (in numbered order) to the GEE *Code Editor*.
3. Make sure to set the `IS_DEBUG` variable to `true` if you just want to visualize the results on the map.
4. Set `IS_DEBUG = false` to run the definitive export.
5. Start the tasks generated by Earth Engine in the *Tasks* tab. Make sure to wait for the previous step's task to finish before running the next step's script.
